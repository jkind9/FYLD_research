# ARCore and Android phone telemetry inventory

**Checked:** 5 October 2026. This is a documentation review, not a phone measurement. It compares 24 named ARCore and Android inputs with the project's five processing layers. Vendor ranges and capability statements below are not project accuracy results.

## Device-list and runtime status

Google's current [supported-device table](https://developers.google.com/ar/devices) names Galaxy S23, S23 FE, S23 Ultra and S23+ as supporting the Depth API. It also names Redmi Note 11 Pro and Redmi Note 11 Pro 5G as supporting the Depth API. The table does not show the supplied Redmi model code `2201116TG`. These are product-name entries, not a runtime check of either handset. Task08's received Redmi APK does not include the ARCore SDK, and Samsung access is unconfirmed, so runtime ARCore support on both project handsets is untested.

The public table's feature-specific comment is the Depth API flag. For other rows, “not enumerated” means the table does not give that per-feature status. It does not mean unsupported. “Not tested” means this project has not checked the feature on the physical handset. Google certification and product-family names do not establish the output, timing, accuracy, phone-specific availability or suitability for a project measurement.

## Recording proposal and limits

The first useful ARCore recording would preserve the camera stream, frame timestamps, selected camera configuration, tracking state/reason, camera pose, CPU and GPU intrinsics, depth mode, raw depth, confidence, and each depth image timestamp. It should also record the requested feature configuration, runtime support results, sensor events with their units and timestamps, device/build identity, and any dropped or unavailable values. If a field is needed after playback, the recorder must explicitly save it and a playback check must confirm it survives. The default MP4 is not proof that all these outputs are present.

Tasks08 and 24 do not provide an ARCore recorder. The current Task08 Camera2 APK has no ARCore SDK and correctly reports ARCore checks as skipped. Task24 owns the print-only build/export path. A phone run or app change requires a separate owner decision, the SDK, and a separately scoped or revised task. This research does not authorize that work.
